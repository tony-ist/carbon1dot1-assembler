## Project Overview

This is a Rust-based assembler and disassembler for the Carbon1.1 architecture, a custom 8-bit instruction set. The assembler supports bidirectional assembly/disassembly with a complete toolchain pipeline.

Carbon 1.1 ISA is the README.md.

## Development Commands

```bash
# Build the project (requires Rust toolchain)
cargo build

# Run tests
cargo test

# Assembly mode - convert .s files to binary
cargo run -- input.s -o output.bin
```

## Architecture Pipeline

The assembler follows a multi-stage compilation pipeline:

1. **Parsing** (`parser.lalrpop`) - LALRPOP grammar-based parser generates AST
2. **Name Mangling** (`name_mangling.rs`) - Function and label name processing  
3. **Label Lowering** (`lower_labels.rs`) - Convert labels to memory addresses
4. **Assembly** (`assembler.rs`) - Generate 8-bit binary machine code

## Key Source Organization

- `src/parser.lalrpop` - Grammar definition (regenerated by build script)
- `src/ast.rs` - Abstract syntax tree definitions for all instruction types
- `src/main.rs` - CLI interface using clap
- `examples/` - Complete sample programs including Fibonacci, Collatz, bit shifting tests

## Carbon1.1 ISA

The custom instruction set includes ~32 opcodes across categories:
- Arithmetic: ADD, SUB, INC, DEC, NEG
- Logic: AND, OR, XOR, BSL, BSR  
- Memory: LIM, RST, RLD, MST, MLD
- Control: BRC, CAL, RET, JMP, JID
- Stack: PSH, POP
- I/O: PST, PSI, PLD, PRD

## Build System Notes

- Uses LALRPOP build script (`build.rs`) to generate parser from grammar
- Parser regeneration happens automatically on grammar changes
- Binary output format is 8-bit instruction encoding written as binary strings
